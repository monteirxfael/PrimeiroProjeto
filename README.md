# Sistema de Gestão de Chamados - Android

Este projeto é um aplicativo Android desenvolvido para a disciplina de Desenvolvimento Mobile no IFSULDEMINAS - Campus Poços de Caldas. 
O objetivo principal é gerenciar a abertura e visualização de chamados técnicos.

## 🚀 Funcionalidades
- **Listagem Dinâmica:** Utilização de `RecyclerView` para exibição dos chamados.
- **Persistência de Dados:** Uso de `SharedPreferences` para salvar as informações localmente.
- **Interface Intuitiva:** Layout estruturado com `ConstraintLayout` e componentes do Material Design.
- **Padrão Adapter:** Implementação de `ChamadoAdapter` para gerenciamento eficiente da lista.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java
- **IDE:** Android Studio
- **Controle de Versão:** Git / GitHub (via WSL/Ubuntu)

## 📁 Estrutura do Projeto
- `app/src/main/java`: Contém a lógica de negócio e os adaptadores.
- `app/src/main/res/layout`: Contém os arquivos XML de definição visual.
